# H_GAME — سعيدة الصوالحة

لعبة تجول من منظور الشخص الأول مبنية حول إحداثيات سعيدة الصوالحة:
`18.58979, 41.4123419`

## ما هو موجود الآن
- طرق ومبانٍ تُجلب من بيانات OpenStreetMap الحقيقية حول الموقع.
- تحويل الإحداثيات إلى عالم ثلاثي الأبعاد بمقياس قريب من المتر.
- حركة منظور شخص أول على الكمبيوتر والجوال.
- أرض منبسطة عمدًا وعدم إضافة جبال أو تضاريس غير موثقة.
- ألوان وارتفاعات مبانٍ محافظة عندما لا تتوفر بيانات ارتفاع حقيقية.

## مبدأ الواقعية
موقع الطريق وكتلة المبنى يمكن أن تأتي من OSM، لكن شكل الواجهة، السور، الشجرة، العمود، اللوحة أو مدخل المنزل لا يعتبر مطابقًا للواقع إلا عند وجود مرجع أرضي موثوق. المشروع يتجنب اختلاق المعالم الكبيرة.

## التشغيل
شغّل خادم ملفات محليًا ثم افتح الصفحة:

```bash
python3 -m http.server 8080
```

ثم افتح:
`http://localhost:8080`

## الهدف
المرحلة الحالية تؤسس خريطة قابلة للتجول. التحسين التالي هو توثيق الشوارع والمنازل بالصور والفيديوهات وربط كل مرجع بإحداثياته ثم استبدال الكتل العامة بنماذج أقرب للواقع.
