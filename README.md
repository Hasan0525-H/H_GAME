# H_GAME — سعيدة الصوالحة

لعبة تجول من منظور الشخص الأول مبنية حول الإحداثيات:
`18.58979, 41.4123419`

## قاعدة التنفيذ
المشروع يتبع قاعدة صارمة: **لا نضيف معلمًا بصريًا على أنه موجود فعلاً إلا إذا كان مدعومًا ببيانات خريطة أو مرجع أرضي موثوق.**

## ما يُرسم الآن
- الطرق المرسومة في OpenStreetMap.
- بصمات المباني المرسومة في OpenStreetMap.
- ارتفاع المبنى إذا كان `height` أو `building:levels` موثقًا.
- الأسوار والحواجز إذا كانت مرسومة كـ `barrier`.
- الأشجار فقط إذا كانت موثقة كعقدة `natural=tree`.
- أعمدة الكهرباء والإنارة فقط إذا كانت موثقة.
- استخدامات الأراضي والرمل والمزارع فقط عند وجود الوسم المقابل.
- اسم الطريق قرب اللاعب إذا كان الاسم موجودًا في البيانات.

## ما تم منعه عمدًا
- لا جبال مولدة.
- لا أشجار عشوائية.
- لا أعمدة كهرباء عشوائية.
- لا خطوط طريق وسطية إلا إذا كانت موثقة بوسم صريح.
- لا أرصفة إلا إذا كانت موثقة.
- لا تفاوت عشوائي في ارتفاعات أو ألوان المنازل.
- لا سقوف أو واجهات مخترعة.
- مجرى الماء لا يتحول تلقائيًا إلى ماء ظاهر إذا لم تدعم البيانات ذلك.

## العناصر غير المكتملة
إذا كانت بصمة مبنى موجودة لكن ارتفاعه غير معروف، تُعرض كتلة حيادية منخفضة فقط للدلالة على موقعه، ولا تُعامل كشكل مطابق للمنزل الحقيقي.

## التشغيل
```bash
python3 -m http.server 8080
```

ثم افتح:
`http://localhost:8080`

## الخطوة التالية
إضافة تفاصيل المنازل والشوارع من صور وفيديوهات أرضية مرتبطة بمواقع محددة، مع حفظ كل مرجع وإحداثياته قبل تحويله إلى نموذج داخل اللعبة.
